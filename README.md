# 📚 도서관 공익 시뮬레이터

공공도서관 **어린이자료실**에서 근무하는 사회복무요원(공익)의 하루를 옮긴 **타임 매니지먼트 직업 시뮬레이션** 게임입니다.
09:00 출근부터 18:00 퇴근까지, 쏟아지는 반납 책과 업무 시간표를 버텨 내세요.

## 플레이
- 브라우저에서 바로: GitHub Pages 링크
- 로컬: `node serve.js` 실행 후 http://localhost:8123

## 하루 흐름
- **오전** — 자동반납기·천장 레일 이송기 책을 데스크로 → 프린터 용지 확인 → AR·영어 태블릿 배치 → 신문 → 잡지(1일·15일)
- **오후** — 타관도서 묶기 → 포터 상하차(비슷한 도서관 이름 주의!) → 지하 컨베이어(끈 제거) → 근무실 반납기 스캔 → 기울어진 책 세우기
- **상시** — 반납기 5권씩 스캔(책갈피 주의) · 청구기호 순서대로 배가 · 신착 · 책 땡기기(칸 끝번호 5·0)와 라벨링

## 재미 요소
- 🔥 연속으로 일을 해내면 콤보 점수
- 🧒 이용자 돌발 상황 (Z/X/C로 대응)
- 🎒 유치원 단체 방문 러시 (점수 ×1.5)
- 🎁 퇴근길 아이템 장만, 소집해제 D-365까지

## 조작
`Q` `W` `E` `R` `T` `Y` 장소 이동 · 데스크: `Space` 올리기/스캔, `B` 책갈피, `1`~`3` 분류 · `M` 음악 · `N` 효과음

외부 라이브러리·에셋 없이 순수 HTML/CSS/JavaScript와 Web Audio로 만들었습니다.
